☁️ Guardar en la nube

Tus datos se guardan automáticamente en este navegador. Para tener respaldo en la nube y usarlo desde cualquier dispositivo, exporta el archivo y guárdalo en Google Drive, Dropbox o OneDrive. Vuelve a importarlo cuando quieras.

El Excel incluye una hoja por cada apartado: Flujo de caja, Resumen mensual, Quincenal, Deudas y amortización, Alertas y Configuración. El respaldo (.json) guarda absolutamente toda la información para restaurarla tal cual.

🔗 Vincular con base de datos o tabla de Excel

Aquí puedes conectar tu información con la nube en dos direcciones: traer datos desde un enlace (lectura) y enviar toda tu información a un enlace (escritura), para no saturar el almacenamiento local del navegador.

1) Enlace para LEER datos (Excel/CSV/Google Sheets)

Trae la información del enlace. Si usas tu Apps Script y añades ?format=json al final (…/exec?format=json), se restaura todo el respaldo: todos los años con la frecuencia y la cuenta de cada mes. Si el enlace devuelve una tabla (CSV/Excel o …/exec normal), se cargan los montos del año activo. El enlace debe ser público; si el sitio bloquea el acceso (CORS), descarga el archivo y usa “Importar Excel”.

2) Enlace para ENVIAR toda la información (guardar en la nube)

Envía toda la información (todos los años, cada mes, frecuencia, cuenta, deudas y configuración) en formato JSON al endpoint indicado, conservando cada espacio. Un enlace normal de Excel/Google Sheets no puede recibir datos: necesitas un endpoint que acepte POST, por ejemplo una Google Apps Script Web App conectada a tu hoja. Así la información vive en la nube y el navegador no se satura.
